# Виртуальное пространство для проведения онлайн пар

КУБ — VR/desktop-аудитория на Unreal Engine 5.7. Преподаватель создаёт LAN-комнату, студенты входят по коду и работают с общей доской, указателем, экраном и учебным двигателем ВАЗ-2112.

## Скачать готовую игру

Откройте [последний релиз](https://github.com/vacek225/vr.diplom/releases/latest) и скачайте **KUB-Windows-x64-v0.1.0.zip** из Assets. Это готовое приложение; архивы Source code предназначены для разработки.

1. Распакуйте ZIP целиком в отдельную папку. Не запускайте EXE внутри архива и не переносите его отдельно от Engine и игровых данных.
2. При отсутствии Visual C++ Runtime установите `Prerequisites/vc_redist.x64.exe`.
3. ПК: `Start_PC.bat`. VR: запустите SteamVR, выберите его активной средой OpenXR, проверьте tracking и выполните `Start_VR.bat`. Unreal Editor перед VR-запуском закройте.

Редактор и Git для готовой игры не нужны. Требуются Windows 10/11 x64, поддержка DirectX 12 и актуальный видеодрайвер. SteamVR устанавливается отдельно. Совместимость с любым произвольным компьютером не гарантируется; macOS/Linux и автономные VR-шлемы этой сборкой не поддерживаются.

## Скачать исходный проект

Установите Git и [Git LFS](https://git-lfs.com/), затем выполните:

```powershell
git lfs install
git clone https://github.com/vacek225/vr.diplom.git
cd vr.diplom
git lfs pull
git config core.quotepath false
```

Все .uasset и .umap хранятся в LFS. После клонирования убедитесь, что это реальные ассеты, а не текстовые LFS-указатели. Для исходников используйте Git + LFS: обычный ZIP репозитория может не включать содержимое LFS.

## Подготовить другой компьютер для разработки

- Unreal Engine **5.7** для Windows с C++ tooling, через Epic Games Launcher.
- Visual Studio 2022: **Game development with C++** и **Desktop development with C++**, MSVC v143 14.44 и Windows SDK. Epic рекомендует VS 17.14 для UE 5.7; подробности — в [официальной инструкции](https://dev.epicgames.com/documentation/en-us/unreal-engine/setting-up-visual-studio-development-environment-for-cplusplus-projects-in-unreal-engine?application_version=5.7).
- Для тестирования HTC VIVE: SteamVR и активный SteamVR OpenXR runtime.

В PowerShell из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\Scripts\OpenProject.ps1 -EngineRoot "D:\UE_5.7"
```

Замените путь на свой. Скрипт собирает C++ из исходников и открывает `.uproject`. Альтернатива: откройте `.uproject` в UE 5.7 и согласитесь на компиляцию модулей. `UE_ROOT` либо зарегистрированная установка могут использоваться вместо параметра.

Начальная карта — `/Game/VRTemplate/Lobby`; аудитория — `/Game/VRTemplate/3_Block`. Без активного HMD доступно управление ПК. Первый запуск может долго компилировать шейдеры. Не нужно запускать Editor-скрипты подготовки ассетов: подготовленные материалы, уровни и input assets уже включены.

## Сборка и упаковка

```powershell
powershell -ExecutionPolicy Bypass -File .\Scripts\BuildEditor.ps1 -EngineRoot "D:\UE_5.7"
powershell -ExecutionPolicy Bypass -File .\Scripts\PackageWindows.ps1 -EngineRoot "D:\UE_5.7"
```

Второй скрипт создаёт Windows Development DX12-сборку в `Builds/Windows`. Перед упаковкой закройте Editor, отключите Live Coding и сохраните карты. Для самостоятельной раздачи добавьте лаунчеры из релиза и VC++ redistributable.

## Структура

- `Source/` — постоянный основной C++-модуль и Game/Editor targets; не зависит от `Intermediate/Source`.
- `Plugins/KemSUinVR/Source/` — комнаты, UI, захват, рисунки, указатель, двигатель и тесты.
- `Plugins/NodeToCode/` — исходники необязательного Editor-плагина; отключён по умолчанию. Его лицензия сохранена внутри каталога плагина.
- `Content/`, `Config/`, `Build/` — уровни, Blueprint, материалы, текстуры, ввод и настройки упаковки.
- `Scripts/Editor/` — утилиты подготовки; не запускайте их на пакетах одновременно с редактированием.
- `Docs/PROJECT_NOTES.md`, `agents.md` — подробные заметки по реализации. В старых заметках встречаются исторические настройки; актуальные допуски установки — 16 см и 55°.

`Binaries`, `Intermediate`, `Saved`, DDC, кэши IDE, тестовые логи и packaged build исключены из Git. Бинарные модули компилируются на новом компьютере. Основной проект не требует скачивания отдельного приватного плагина или API-ключей.

## Управление и возможности

ПК: Esc — меню, F — удержание, R + мышь — вращение. VIVE: Menu — панель, курок — UI/инструмент, Grip — держать предмет, отпускание — освободить. Панель можно переносить курком за внешнюю рамку. При включённом указателе курок притягивает разрешённые предметы; Grip переводит их в обычное удержание.

Двигатель создаётся через меню «Объекты», включая Lobby без LAN-сессии. Учебные режимы — свободный, разборка и сборка. Подсветка, зависимости и локальная прозрачность помогают установить деталь. В аудитории состояние деталей реплицируется. В LAN разрешите приложению доступ в частной сети брандмауэра.

## Проверка и ограничения

Unreal Automation: `Automation RunTests KemSUinVR`. Физические HTC VIVE, совместимость драйверов и работа двух компьютеров LAN требуют ручной проверки; 90 FPS не заявляются как подтверждённый результат.

Текущая сеть — **listen server в LAN**. Dedicated Server, интернет-сервис комнат, сохранение результатов и ИИ-помощник остаются направлениями развития. Общий экран синхронизирует URL, а не видеопоток, прокрутку, авторизацию или время воспроизведения. Загрузка локальных PDF/PPTX/видео не реализована. Обычные предметы Lobby притягиваются локально, сетевой захват реализован для деталей двигателя.

Модель двигателя учебная и упрощённая, не заводской CAD. Ссылка MediaSource IMG_3324 указывает на отсутствующее внешнее видео; оно не включено ни в исходники, ни в релиз, и соответствующая поверхность может оставаться пустой. Это не препятствует основным игровым сценариям.

Релиз v0.1.0 содержит проверочную Windows-сборку **от 22.10.2026**; исходный проект перенесён **05.11.2026**. Окружение разработки, движок и SteamVR не включаются в Git и устанавливаются отдельно. Отдельный PDB не включён в пользовательский ZIP, остальные игровые зависимости сохранены.
